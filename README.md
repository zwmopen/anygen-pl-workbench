# AnyGen Local Workbench

一个本地运行的 AnyGen 工作台，用来做手动生成、批量生成和定时生成。

## 当前状态

这个项目目前已暂停维护，保留为公开作品集和本地 AI 工作流实验记录。

它曾经的目标是把 AnyGen 的调用、本地素材、批量任务和定时执行集中到一个本地工作台里。现在更成熟的 AI 工具和更直接的工作流已经覆盖了大部分需求，所以这个项目暂时不再继续打磨。

## 它想解决什么问题

当时的核心问题是：AI 生成任务越来越多，但素材、提示词、表格任务、输出目录和定时执行都很分散。

这个项目尝试解决：

- 手动发起提示词任务
- 上传参考图、参考文档和本地附件
- 按文件夹批量处理生成任务
- 从 `.xlsx` / `.csv` 表格导入任务
- 每天定时执行固定生成流程
- 把结果保存回本地目录
- 做成可打包给别人使用的本地工具

它本质上是一个“AI 生成任务调度台”。

## 设计思路

设计上优先考虑本地可控和批量效率：

- 本地 Web 界面负责组织任务
- Node 服务负责读取本地文件和调用生成接口
- 文件夹可以直接作为任务单位
- 表格可以作为批量任务清单
- 输出尽量回到原始目录，减少整理成本
- 通过便携版和安装包降低交付门槛

它想把“我有一批素材和一批提示词”这件事，从手动复制粘贴变成一个可重复的工作流。

## 后来的反思

这个项目的方向仍然有价值，但未必需要以一个独立工作台的形式长期存在。

AI 时代真正重要的不是再做一个壳，而是把工作流细节沉淀清楚：输入是什么、判断标准是什么、输出格式是什么、如何验收、如何复用。

如果这些流程已经能通过更轻量的脚本、技能、自动化或现成工具完成，一个完整本地工作台的维护成本就显得偏高。

## 是否继续维护

暂不维护。

后续如果重新启动，更可能拆成几个更小的工作流模块，而不是继续做成一个完整平台：

- 批量任务规范
- 文件夹输入约定
- 表格任务模板
- 输出验收规则
- 可复用的 AI 技能或脚本

## 技术栈

项目主要基于 JavaScript / Node.js 构建，包含本地 Web 页面、文件夹扫描、表格导入、定时任务注册、便携版和安装包打包流程。

## 作品集说明

这个仓库展示的是一次“本地 AI 生产工作台”的尝试。它现在不是主力工具，但保留了对批量生成、本地素材管理和 AI 工作流产品化的探索。
